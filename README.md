# PrimeForge

PrimeForge is a research project for auditable prime-search, proof, and verification workflows. The project is governed by its versioned research specification and uses explicit scientific-status labels.

The current repository is in the foundations phase. It makes no claim of superior performance, mathematical novelty, or discovery of a new prime.

See `CHARTER.md`, `CLAIMS.tsv`, `DECISIONS.md`, and `docs/specifications/` before interpreting any result.
