# PrimeForge source audit template

- Name:
- Primary URL:
- Revision:
- Source/archive SHA-256:
- License at revision:
- License-file SHA-256:
- Evidence level: DOC_VERIFIED, SOURCE_AUDITED, or REPRODUCED
- Mathematical domain:
- Main algorithms:
- Supported sizes/forms:
- CPU/GPU:
- Vectorization/assembly/FFT/NTT:
- Threading:
- Memory structures and block sizes:
- Checkpoints and error controls:
- Proofs/certificates:
- Input/output formats:
- Platform status:
- Supplied test status:
- Simple reproduced case:
- Raw performance:
- Author-declared limits/TODO:
- Integration risks:
- Redistribution decision:
- PrimeForge decision: LINK, ADAPTER, REFERENCE_ONLY, or REJECTED

Rules:

1. DOC_VERIFIED means that a claim was checked in the pinned documentation.
2. SOURCE_AUDITED additionally requires inspection of the pinned source.
3. REPRODUCED requires an exact local build or official binary and a recorded command.
4. External performance statements remain author-reported and are not PrimeForge benchmarks.
5. NOT_RUN is not a failure of the program; it describes the present audit environment.
6. A PRP result is never recorded as a primality proof.
